📊 详细路径推导
关键规则复习：格子的数字=必须走的步数（移动次数）

第一步：从起点S出发
• S在(1,1)，周围只有右边(1,2)可以走
• 进入(1,2)，数字=2，必须走2步

第二步：从(1,2)出发，走2步
• 选项A：右→右 → (1,3)→(1,4)是墙 ❌
• 选项B：右→下 → (1,3)→(2,3) ✅ 可行！
• 选项C：下→右 → (2,2)→(2,3) ✅ 可行！
• 选项D：下→下 → (2,2)→(3,2) ✅ 可行！

第三步：选择选项C继续（下→右到(2,3)）
• 在(2,3)，数字=2，必须走2步
• 右→右：(2,3)→(2,4)→(2,5)是墙 ❌
• 右→下：(2,3)→(2,4)→(3,4) ✅ 到达(3,4)！
• 下→右：(2,3)→(3,3)是墙 ❌

第四步：从(3,4)到终点
• 在(3,4)，数字=1（修改后），只需走1步
• 向右1步：(3,4)→(3,5)=E ✅ 到达终点！

🔄 其他可行路径探索
路径二（也是6步）：
S→(1,2)[右→下]→(2,3)[右→下]→(3,4)[右]→E
即：S→右→右→下→右→下→右→E = 6步

路径三（绕远路，约8-10步）：
S→(1,2)[下→下]→(3,2)[?]→...
从(3,2)数字2出发，可以向下到(4,2)，但后续路径会比较复杂

为什么修改这个数字？
原来第3行第4列是数字2，意味着要从这里走2步才能离开。
但(3,4)右边就是终点E，走2步会越过终点！
改成数字1后，从(3,4)走1步正好到达E，逻辑更合理 ✅
💡 解题技巧总结
方法：分支枚举法
1. 从起点列出所有可能的走法
2. 每到一个新格子，根据数字继续分支
3. 排除撞墙、出界的分支
4. 找到能到达终点的有效路径

易错提醒：
❌ "走2步"不是指走到第2个格子，而是移动2次！
❌ 每次移动都要检查目标位置是否可通行
✅ 建议用铅笔在纸上标注路径，避免走回头路

💡 为什么这样设计路径？
为什么第5行要向左走？
观察第6行的障碍分布：
- (6,5)是墙壁❌ 不能从这里下去
- (6,6)虽然可以下去，但(6,7)是◀️会把人引向左边
- 只有(6,4)是安全的空白通道✅

如果用(6,7)◀️向左，会走到(6,6)，再向下到(7,6)... 这样也可以到达终点。
但本答案选择了更直观的"第5行左移→第6行直下→第7行冲刺"路线。

🎯 避开陷阱区（第3行▶️🔼◀️循环）
🎯 利用给定方向（第3行🔽向下穿行）
🎯 寻找安全出口（第5行左移找(6,4)通道）
🎯 最后直线冲刺（第7行一路向右）

拔高
✅ 标准答案
路径：1,1,1→1,1,3(↕️)→2,1,3→2,2,2(↕️)→3,2,2→3,2,4→E
或：S→(1,3)楼梯→(2,3)→(2,2)楼梯→(3,2)→(3,4)→E
📊 详细解析
立体迷宫的关键：楼梯(↕️)可以连接不同层。

1. 从第1层S(1,1)出发
2. 向右走到(1,3)，这里有楼梯↕️，上到第2层
3. 在第2层(1,3)，向下走到(2,3)
4. 向左走到(2,2)，这里有楼梯↕️，上到第3层
5. 在第3层(2,2)，向右走到(2,4)就是E

注意：需要确认每层楼梯的位置是否对应。
💡 思维点拨
立体迷宫培养孩子的空间想象力。建议用实物辅助教学：用3张纸代表3层，在楼梯位置剪洞，用线连接，帮助孩子理解"层与层之间的关系"。

迷宫综合挑战
拔高
✅ 标准答案
(1) 无障碍时：3432条路径
(2) 有障碍时：需要标数法计算，约500+条（具体数值需完整标数）
📊 详细解析
(1) 无障碍情况：
从(1,1)到(8,8)，需要向右走7步，向下走7步，共14步。
路径数 = C(14,7) = 14!/(7!×7!) = 3432

(2) 有障碍情况：
使用标数法，遇到障碍标记为0：
- 第1行：1, 1, 1, 0, 0, 0, 0, 0
- 第2行：1, 0, 1, 2, 0, 0, 0, 0
- 第3行：1, 1, 2, 0, 0, 0, 0, 0
- ...（需要完整计算）

由于障碍较多，实际路径数会大大减少。
💡 思维点拨
这道题是组合数学的经典问题。C(2n-2, n-1)的公式要记住！对于障碍情况，标数法是通用解法。可以引申到"网格路径"问题，这是信息学奥赛的基础题型。

总路径数 = C(6,3) = 6!/(3!×3!) = 20条

(1) 不能经过(1,1)和(2,2)：
使用容斥原理：

• 经过(1,1)的路径数：
(0,0)→(1,1)：C(2,1) = 2条
(1,1)→(3,3)：C(4,2) = 6条
共：2 × 6 = 12条

• 经过(2,2)的路径数：
(0,0)→(2,2)：C(4,2) = 6条
(2,2)→(3,3)：C(2,1) = 2条
共：6 × 2 = 12条

• 同时经过(1,1)和(2,2)的路径数：
(0,0)→(1,1)：C(2,1) = 2条
(1,1)→(2,2)：C(2,1) = 2条
(2,2)→(3,3)：C(2,1) = 2条
共：2 × 2 × 2 = 8条

• 根据容斥原理：
答案 = 总路径 - 经过(1,1) - 经过(2,2) + 同时经过两者
= 20 - 12 - 12 + 8 = 4条

(2) 不能连续经过(1,1)和(2,2)：
连续经过意味着路径为：(0,0)→...→(1,1)→(2,2)→...→(3,3)
这样的路径数 = 8条（上面已计算）
答案 = 20 - 8 = 12条
💡 思维点拨
这是容斥原理的经典应用！公式：|A∪B| = |A| + |B| - |A∩B|

对于"不能经过某些点"的问题：
1. 计算总路径数
2. 减去经过禁点的路径数
3. 加回重复减去的部分（同时经过多个禁点）

这是组合数学和信息学奥赛的重要基础！
